\begin{abstract}
A paper is typically written in \LaTeX{} and read as a PDF, while readers increasingly
come to it through a web page. When the two are maintained separately they drift apart.
We describe a setup where the \LaTeX{} source is the single source of truth, the web page
is a deterministic build of it, and a commit hook refuses any commit in which the published
page is not the build of the committed source.
\end{abstract}

\section{Introduction}\label{sec:intro}

Preprints are written once and rendered many times. Each manual rendering is a chance for
the copies to disagree. Pandoc~\cite{macfarlane2006pandoc} converts \LaTeX{} to HTML with
MathML math, so the web rendering can be computed instead of edited by hand.
Section~\ref{sec:sync} defines what \emph{in sync} means and how it is enforced.

\section{The Sync Invariant}\label{sec:sync}

Let $s$ be the committed source and $b(s)$ the HTML page that the build produces from it.
The build is deterministic, so $b(s)$ is a function of $s$ alone. Let $p$ be the page
currently published. The repository is in sync when
\begin{equation}\label{eq:sync}
  h\bigl(b(s)\bigr) = h(p),
\end{equation}
where $h$ is SHA-256. We cannot hash $p$ remotely, so we record $h(p)$ at publish time.
The commit hook rebuilds $b(s)$ and checks Equation~\eqref{eq:sync} against that record.
